# 개조 알까기

알을 튕겨 상대를 판 밖으로 밀어내고, 바퀴가 지날 때마다 부품을 골라 내 알에 장착하는 2~8인 턴제 대전. Godot 4.7 (2D, GL Compatibility)로 만들고 웹으로 내보낸다.

- 휴대폰·패드: 화면 모양에 따라 기준 해상도를 고른다 (휴대폰 세로 480, 패드 세로 680, 휴대폰 가로 1100×600, 그 밖 1280×800). 대기실은 화면보다 길면 밀어서 내려 보고, 좁으면 한 열·가로형 개조 카드로 바뀐다. 터치로 조준한다.
- 제목·배너 글꼴: Black Han Sans (SIL OFL, `fonts/OFL-BlackHanSans.txt`).
- 같은 기기에서 번갈아 두거나, 「친구 초대 링크」로 친구를 불러 각자 기기에서 둔다. 자리마다 사람/CPU/친구를 고른다.
- 매 바퀴 시작에 부품을 고르고, 바퀴 제한 없이 한 명만 남을 때까지 둔다.
- 부품 66종 (기계 32 · 마법·각성 12 · 애니 패러디 10 · 마법 12), 알 하나에 무기·보조·추진 슬롯 하나씩. 패러디 부품이 발동하면 그 알이 흑백 만화 그림체로 바뀌고 효과음이 뜬다.
- 세트 3종 (메카 티라노 「물고 던지기」, 달그림자 마도사 「궤도 마법」, 최후의 주인공 「라스트 컷」). 메카 티라노 세트: 티라노 머리·팔·다리를 한 알에 모으면 변신하고 「물고 던지기」가 열린다. 티라노 부품이 있으면 다음 개조 후보 한 자리는 빠진 티라노 부품.
- 2인 정사각형 판(퍽 4개), 3~4인 원형(퍽 3개), 5~8인 넓은 원형(퍽 3개, 조준 8초 기본).
- 모드: 「최후 생존전」(한 명 남을 때까지) / 「개조 더비」(2~4인 8바퀴, 5~8인 6바퀴. 떨어진 퍽은 다음 바퀴에 부품을 단 채 복귀, 상대 퍽을 떨어뜨리면 1점).
- 오늘의 공방: 고물 정비소 · 마법 상점 · 만화 창고(공용 10종 + 전용 6종) / 무작위 / 전체. 공방마다 완성할 수 있는 세트가 하나씩 있다.
- 개조 후보 3장 중 2장 이상은 비어 있는 슬롯에 맞는 부품. 카드에 발동 시점·움직임 화살표·한 줄 설명.
- 공방 경기장(디자인 「오늘의 공방 프로토타입」): 맵을 「공방 따라가기」(기본)로 두면 고물 정비소는 철판과 노랑·검정 경고 띠, 수상한 마법 상점은 별밤과 마법진, 만화 소품 창고는 종이·먹선·망점으로 그려지고 패널 모양도 공방을 따라간다. 로비는 두 열(설정 / 배치 미리보기·공방 간판 카드·모드·공방 열기), 시작하면 셔터가 올라가며 공방을 소개한다. 위쪽 가운데 바퀴 칩, 부품 패널의 세트 진행 막대, 개조 카드(슬롯·세트 배지, 「빈 슬롯에 바로 장착 / 기존 부품과 교체」, 나눠주기 모션), 「이번 바퀴 개조 공개」 알림.
- 맵 3종(밝은 놀이판 · 장난감 공방 · 선명한 다크): 로비와 경기 중 메뉴(≡)에서 고르고 기기에 기억한다. 초대 대전은 방장의 맵. 경기장과 HUD 색은 `scripts/themes.gd` 한 곳에서 읽는다.
- 퍽: 윗면 전체가 주인 색, 각인은 항상 똑바로, 정면은 테두리 홈. 충돌 히트스톱·화면 흔들림·눌림·불꽃, 조준 고무줄, 발사 튐, 잔상, 위험 구역 깜빡임, 탈락·차례 배너·장착·승리 색종이 연출. 설정에서 흔들림·히트스톱·움직임 줄이기, 효과음·배경음악·화면 소리 볼륨.
- 힘 곡선: 0.65칸 미만 당김은 취소, 3.2칸이 최대. 1칸 당기면 약 3칸, 끝까지 당기면 약 10칸 미끄러진다 (반발 0.7). 사양 값(최대 15.5칸, 반발 0.9)은 판이 너무 빨리 끝나서(4인 평균 4.6바퀴) 최대 힘과 반발을 낮춰 약 6.7바퀴로 맞췄다. 시간은 2.5배 빠르게 돌려 부품이 미는 거리는 예전과 같다. 퍽이 떨어진 자리에 「누가 · 무슨 부품으로」 원인 표시. CPU 차례 「▶▶ 빠르게」, 내 차례는 황동 테두리로 강조.

## 실행

### Godot 설치 (Windows)

```bash
winget install --id GodotEngine.GodotEngine -e
```

또는 https://godotengine.org/download/windows 에서 **Godot 4.7 (Standard)** zip을 받아 압축을 풀면 바로 실행된다. 설치 후 Godot을 열고 **가져오기(Import)** → 이 폴더의 `project.godot` 선택 → **F5**로 실행.

웹으로 내보내려면 export templates가 필요하다. 에디터에서 **편집기 → 내보내기 템플릿 관리 → 다운로드 및 설치**를 한 번 해 두면 된다.

### 웹 빌드

```bash
godot --headless --path . --export-release "Web" docs/index.html
python -m http.server 3700 --directory docs
```

`http://localhost:3700`. 스레드를 쓰지 않는 웹 빌드라 GitHub Pages처럼 특별한 헤더가 없는 정적 호스팅에서 그대로 돈다. 저장소 설정의 Pages를 `main` 브랜치 `/docs` 폴더로 두면 된다.

## 구조

판정·물리·연출을 나눴다. `scripts/sim/` 은 화면 없이 돌아가며, 같은 입력이면 항상 같은 결과가 나온다 (온라인 대전 때 모두가 같은 충돌을 보게 하기 위한 바탕).

| 파일 | 내용 |
|---|---|
| `scripts/sim/parts_data.gd` | 부품 20종의 슬롯, 발동 시점, 설명, 충격량·사거리 같은 수치 |
| `scripts/sim/parts.gd` | 부품 효과: 발사·첫 충돌·측면 충돌·정지 사건에 반응. 조준선 미리보기 |
| `scripts/sim/world.gd` | 고정 간격(1/120초) 원형 알 물리, 탄환, 거울·지뢰·방울·포탑, 탈락 판정. 복제해서 미리 돌려볼 수 있다 |
| `scripts/sim/match.gd` | 차례, 바퀴, 시작 자리 넘기기, 개조 일정, 장착, 승패(최후 1인 / 바퀴 제한 시 남은 알 수 / 무승부) |
| `scripts/sim/bot.gd` | CPU: 후보 샷을 세계 복제본에서 돌려 보고 고른 뒤 사람처럼 약간 빗나가게 쏜다 |
| `scripts/game.gd` | 입력(당겨서 쏘기), 그리기, HUD, 개조 카드, 결과 화면 |
| `scripts/sim/expansion.gd` | 확장 부품 34종과 두 세트: 발사·이동·충돌·탄·장치·판 끝·탈락·샷 끝 시점의 효과 |
| `scripts/stone_art.gd` | 알과 부품 실루엣 |
| `scripts/art_data.gd` | 확장 부품 도면 (자동 생성: `python tools/svg_to_art.py <시안 Expansion.dc.html> scripts/art_data.gd`) |

## 테스트와 수치 검증

```bash
GODOT=godot tests/run.sh                                         # 판정·물리·부품 72개
godot --headless --path . -s res://tests/smoke_game.gd -- 4      # 화면 코드로 CPU끼리 한 판
godot --headless --path . -s res://tools/simulate.gd -- 4 30     # 경기 길이·탈락률·부품 작동 횟수
```

현재 시험값에서 CPU끼리 둔 결과 (봇은 실제보다 정확하므로 사람끼리면 더 길어진다):

| 인원 | 평균 바퀴 | 탈락이 나온 샷 | 바퀴 제한으로 끝난 판 |
|---|---|---|---|
| 2인 | 6.4 / 12 | 37% | 6% |
| 4인 | 5.6 / 8 | 39% | 13% |
| 6인 | 6.0 / 6 | 36% | 85% |

5~8인은 6바퀴 제한에 대부분 걸린다. 기획서의 시험값 그대로이며, 다인전 바퀴 수는 플레이 테스트 후 조정할 값이다.

## 개발용 실행 인자

```bash
godot --path . -- --auto 4            # 설정 화면 없이 4인전 시작 (빨강만 사람)
godot --path . -- --auto 6 --draft    # 개조 화면부터
godot --path . -- --auto 4 --allcpu --shots <폴더>   # CPU끼리 3배속, 1.5초마다 화면 저장
```

## 친구 초대 (온라인)

호스트가 「친구 초대 링크 만들기」를 누르면 `...?room=코드` 링크가 생긴다. 친구가 열면 호스트의 친구 자리에 앉는다.
연결은 PeerJS 공개 시그널 서버(0.peerjs.com)로 호스트-친구를 직접 잇고(`web/alkkagi_net.js`, 내보낼 때 `docs/`에 복사), 물리가 결정적이라 행동(발사·장착·유품·건너뛰기)만 주고받는다. 호스트가 순번을 매기고 CPU를 계산한다. 친구가 나가면 그 자리는 CPU가 이어 둔다.
일부 회사·학교 네트워크에서는 직접 연결이 막힐 수 있다.

```bash
godot --headless --path . -s res://tests/net_test.gd   # 호스트·손님 두 게임이 한 판 끝까지 같은 결과인지
```
